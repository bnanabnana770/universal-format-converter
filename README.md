\## 怎么用



其实挺简单的：



1\. 双击打开 index.html 这个文件

2\. 把你要转换的文件拖进去，或者点一下选择文件

3\. 选一个你想转成的格式

4\. 点转换，等它弄完，然后下载就行



\## 能转哪些格式



图片那些都能转，比如 PNG、JPG、WebP、GIF、BMP。



文档类的有 TXT、Markdown、HTML、PDF、DOCX。



表格的话有 XLSX 和 CSV。



音视频有 MP3、WAV、OGG、MP4、WebM。



数据格式有 JSON、XML、YAML。



具体能不能从 A 转到 B，你拖进去试试就知道了，大部分常见组合都支持。
